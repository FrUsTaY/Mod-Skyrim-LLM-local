# Руководство для разработчика мода

Этот файл предназначен только для автора мода. Обычным пользователям читать его не нужно.

## Как скомпилировать `LLM_MainController.psc` в настоящий `.pex`

В репозитории по пути `skyrim_mod/Scripts/LLM_MainController.pex` лежит пустой файл-заглушка. Чтобы пользователи могли привязывать скрипт к квесту без ручной компиляции, вам (как автору) нужно скомпилировать этот скрипт один раз у себя и заменить заглушку на реальный рабочий файл.

Благодаря тому, что установщик `launcher.py` теперь автоматически исправляет пути к исходникам SKSE и JContainers, процесс компиляции стал очень простым:

1. **Подготовьте чистую игру:** Убедитесь, что у вас указан правильный путь к игре в консоли мода.
2. **Запустите установку зависимостей:** Запустите `start_setup.bat` и выберите **Пункт 2**.
   - Дождитесь, пока лаунчер скачает SKSE и JContainers.
   - Обратите внимание на надпись `"Исправление путей исходников для Creation Kit..."` и сообщение `[УСПЕХ]`. Это означает, что лаунчер успешно скопировал все необходимые исходники в папку `Data/Source/Scripts`.
3. **Откройте Creation Kit:**
   - Загрузите мастер-файлы (`Skyrim.esm`, `Update.esm`) через `File -> Data...`.
4. **Скомпилируйте скрипт:**
   - В верхнем меню выберите **Gameplay -> Papyrus Script Manager**.
   - В поле Filter введите `LLM_MainController`.
   - Нажмите по нему правой кнопкой мыши и выберите **Compile**.
   - Дождитесь окончания (статус должен быть `Success`).
5. **Заберите готовый файл:**
   - Зайдите в папку вашей игры `Data/Scripts/`.
   - Найдите там свежий файл `LLM_MainController.pex`.
   - Скопируйте его.
6. **Замените заглушку в репозитории:**
   - Вставьте скопированный файл в папку вашего репозитория `skyrim_mod/Scripts/`, согласившись на замену.

Всё! Теперь в вашем репозитории лежит настоящий скомпилированный скрипт, и при установке у пользователей он будет сразу работать. Этот процесс нужно повторять только в том случае, если вы меняете код внутри `LLM_MainController.psc`.
