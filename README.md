# Skyrim Local LLM Voice Mod

Этот мод позволяет общаться с NPC в Skyrim голосом, используя локальные нейросети.

## Особенности
- Распознавание вашей речи на лету (Whisper).
- Интеграция с LM Studio для генерации ответов от лица NPC (Qwen 3 / Gemma 3).
- Учитывает лор, локацию, ваши отношения с NPC, ваше оружие в руках и скрытность.
- Озвучивает ответы на русском языке (Silero TTS).
- Работает полностью локально, без интернета и подписок.

## Требования
- Skyrim Special Edition v1.6.1170.0.8
- SKSE64
- JContainers SE
- Установленный LM Studio

## Установка и запуск

1. Установите папку `skyrim_mod` как мод в вашем менеджере (Mod Organizer 2 / Vortex).
2. Запустите LM Studio, загрузите модель и включите Local Server на порту `1234`.
3. Установите Python 3 и зависимости для сервера: `pip install -r server/requirements.txt`.
4. Запустите Python-сервер перед запуском игры: `python server/src/main.py`.
5. В игре наведите прицел на NPC, зажмите кнопку `V`, скажите фразу в микрофон, затем отпустите кнопку.
